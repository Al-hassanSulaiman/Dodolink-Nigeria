2. Click "My Apps" → "+" → "New App"
3. Platform: iOS
4. Name: Dodolink NG
5. Primary Language: English (Nigeria if available, else English UK)
6. Bundle ID: com.dodolink.ng  ← select from dropdown (appears after EAS build registers it)
7. SKU: dodolink-ng-001  (any unique string you choose)
