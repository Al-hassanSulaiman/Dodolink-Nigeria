---
name: Subscription chat threshold
description: Defines what counts toward subscription eligibility and engagement pricing.
---

Subscription engagement counts distinct customers who send at least one customer message to a store within the rolling 30-day window. The same customer can count again in a later window by chatting again; multiple messages in the same window count once. Reviews, ratings, and review comments do not count.

**Why:** The intended threshold measures how many customers actively chat with a store each rolling period, while preventing message volume from inflating the count.

**How to apply:** Count distinct customer senders from customer messages for the seven-customer eligibility threshold and pricing tiers. Re-check qualification after customer messages in both new and existing threads; never trigger it from reviews or retailer replies.
