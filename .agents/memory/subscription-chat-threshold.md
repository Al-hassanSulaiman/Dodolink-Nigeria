---
name: Subscription chat threshold
description: Defines what counts toward subscription eligibility and engagement pricing.
---

Subscription engagement counts distinct customer-to-store conversation threads created within the rolling 30-day window. Reviews, ratings, review comments, and additional messages in an existing thread do not count.

**Why:** The intended threshold measures how many customers start chats with a store, not general activity or message volume.

**How to apply:** Use conversation records for the seven-conversation eligibility threshold and pricing tiers. Trigger qualification only when a new conversation is created, never when a review is submitted or a message is added to an existing thread.
