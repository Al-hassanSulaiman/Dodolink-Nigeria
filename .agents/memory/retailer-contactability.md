---
name: Retailer contactability
description: Store-profile chat must remain available when a retailer has no products.
---
People must be able to start a chat from a retailer's store profile even if the retailer has not added any products.

**Why:** The user specified that having a store, not having products, should enable retailer contact.

**How to apply:** Keep store-profile contact independent of product listings. Do not hide the chat entry when the product list is empty.
